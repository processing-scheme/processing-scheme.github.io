Welcome to Processing for Scheme!

Processing Scheme Mode lets you write sketches in Scheme using the same ideas you already know from Processing: setup, draw, shapes, color, and interaction. It is built on libprocessing, the same core that powers the new C++ Mode, so every mode shares one fast native renderer.

Scheme Mode is in active development. Docs and examples are not published yet. Follow along on Discord or GitHub.
