What's New

Scheme Mode keeps Processing's names, written the Scheme way: lowercase with dashes. noStroke() is (no-stroke), mouseX is mouse-x, TWO_PI is TWO-PI. These are the other things to know.

Changed
Everything is a list

A call puts the function first, inside parentheses: ellipse(x, y, 20, 20) is (ellipse x y 20 20), and a + b * c is (+ a (* b c)).

Changed
Variables are defined and set

(define x 10) makes a variable, and (set! x (+ x 1)) changes it. There are no types to write.

Changed
Loops

A Java for loop is a do loop:

(do ((i 0 (+ i 1))) ((>= i 10))
  (rect (* i 20) 0 10 10))
Changed
Classes are records

A class becomes a define-record-type with a function for each method, so ball.move() is (ball-move ball) and ball.x = 5 is (set-ball-x! ball 5).

Changed
Methods take the object first

img.get(x, y) is (get img x y), v.add(w) is (add v w) and pg.beginDraw() is (begin-draw pg).

Same
mousePressed works both ways

(define (mouse-pressed) ...) runs once per click, and mouse-is-pressed is true while the mouse is held.
