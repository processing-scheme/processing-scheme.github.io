Libraries Reference Examples About

Libraries

Everything available in Scheme Mode out of the box.

None of these need an import beyond the (import (processing)) every sketch starts with.

Scheme

lists

cons, car, cdr, list-ref, append, map, filter, fold-left, for-each, sort.

vectors

make-vector, vector-ref, vector-set!, vector-length. Java's arrays become vectors.

strings

string-append, substring, string-length, string-upcase, and Processing's split, join and trim.

records

define-record-type, for the classes in Java examples.

hash tables

make-hash-table, hash-table-set!, hash-table-ref. JSON objects are hash tables too.

Processing's classes

PVector

(PVector x y), (add v w), (mag v), (vec-x v), (set-vec-x! v 3).

Images and layers

(load-image "a.png"), (width img), (pixels img), (create-graphics 200 200), (begin-draw pg).

Table / JSON / XML

(load-table "data.csv" "header"), (get-float row "x"), (load-json-object "data.json"), (load-xml "data.xml").

Shapes

(load-shape "bot.svg"), (shape s 0 0), (get-child s "MI").
